## 第一部分：理论不变量与系统公理 (Theoretical Invariants & System Axioms)

### 1.1 第一不变量：主稳定函数与耦合公理

政治系统整体稳定性 $\Psi(t)$ 的内生稳定来源，仅且必须由三个一级基础机制（$M_1, M_2, M_3$）耦合生成：

$$\Psi(t) = f\big(M_1(t), M_2(t), M_3(t)\big)$$

**运行态形式化**（状态依赖权重线性记账形式）：

$$\Psi(t) = w_1(S)\cdot L(t) + w_2(S)\cdot\Phi(t) + w_3(S)\cdot B(t) - C(t,H)$$

其中 $L(t)$、$\Phi(t)$、$B(t)$ 分别为 $M_1$、$M_2$、$M_3$ 的当期产出函数；$w_1(S), w_2(S), w_3(S)$ 为随系统所处状态 $S$ 系统性重组的权重系数；$C(t,H)$ 为路径记忆成本项（$H$ 为系统在当前状态的累积停留历史）。**$\Psi(t)$ 本身是一个记账装置**：在给定状态 $S$ 下，它是三机制产出的线性函数。系统真正不可加总的涌现性质，不体现于 $\Psi(t)$ 的数值本身，而体现于机制间的非线性耦合网络（第五部分）与下述 $P_{cascade}(t)$ 等非线性触发函数。

**一级稳定来源本体定义**：
- $M_1$（合法性与叙事生产）：生产解释现实的认知框架与合规认同。
- $M_2$（控制与原子化）：压制横向组织能力与维持社会原子化。
- $M_3$（资源与激励分配）：维持体制内忠诚与社会经济流动激励。

**私人知识状态变量 $\kappa(t)$**：$\kappa(t)$（微观认知与归因跃迁状态）是与 $M_1, M_2, M_3$ 同级的核心状态变量，但**不作为线性项直接进入 $\Psi(t)$**。其作用渠道是驱动级联触发概率函数 $P_{cascade}(t)$（见第二部分），支配系统向 $S_3$ 分岔区间跃迁的非线性概率。定义为私人知识存量的净增速率：

$$\kappa(t) = \frac{dK_{private}(t)}{dt}$$

**"实现方式 (Implementation)" 公理**：现实中出现的一切新技术、新制度或社会现象（如算法审查、数字货币、网格化监控、债务置换等），**均非新的稳定来源，而仅仅是 $M_1, M_2, M_3$ 在特定历史条件下的实现方式（Implementations）**。

**外部环境变量 $X(t)$ 传导规则**：外部环境冲击（如战争、大流行、地缘制裁）**绝不直接进入主稳定函数 $\Psi(t)$**，仅作为环境状态变量，通过状态更新方程间接扰动一级机制：

$$M_i(t+1) = g_i\big(M_i(t), X(t)\big), \quad i \in \{1, 2, 3\}$$

### 1.2 第二不变量：Level 2 子机制准入与收拢原则

- 严禁创建 $M_4, M_5$ 等新的"一级独立稳定来源"。
- 默认允许新增 Level 2 子机制/子路径，但新增前必须强制优先检查并映射至既有 Level 2 构件。所有子机制必须严格归属于 $M_1, M_2, M_3$ 的因果树之下（例：算法审查 → $P_{algo}$ → $M_2$）。

### 1.3 第三不变量：三状态转换空间与边界

系统研究的一级相态空间仅且必须包含三种状态，严禁创建 $S_4$（崩溃）等终局阶段状态：

$$S_1 (\text{常态治理}) \longrightarrow S_2 (\text{强化治理}) \longrightarrow S_3 (\text{重构危机})$$

**状态边界定义**：

| 状态 | 边界定义 |
|---|---|
| $S_1$ | 常态治理；$w_3$ 最大，绩效资源分配为主要合作激励，强制以背景威慑形式存在 |
| $S_2$-D | 防御型；对外部/内部压力累积的被动强化响应，政权为响应者而非发起者 |
| $S_2$-O | 攻势型；政权最高权威主动发起清洗与重置，排除性、针对性处置逻辑，目标可为精英派系型、產權所有者型或意識形態忠誠標籤型 |
| $S_2$-V | 愿景驱动型；政权主动追求转型性总体愿景，要求全民为实现愿景付出代价 |
| $S_3$-M | 群众驱动型重构危机；须同时满足：来源于下层、规模超越 $M_2$ 遏制能力、目标直接指向政权存续、体制转为被挑战对象 |
| $S_3$-E | 精英驱动型重构危机；须同时满足：精英联盟内部两个以上具相当资源基础的行动者围绕"谁有权代表体制正当性"发生实质性争夺、且已突破体制内部裁决机制所能容纳的边界 |

$\theta_{exit}(S_2\to S_1) \gg \theta_{entry}(S_1\to S_2)$：$S_2$ 退出阈值显著高于进入阈值，二者不对称，源于监控基础设施沉没成本、科层既得利益固化、信息生态自我强化三重制度性来源。

$S_2\text{-D}, S_2\text{-O}, S_2\text{-V}, S_3\text{-M}, S_3\text{-E}$ 均为状态内部的合法连续演化路径分型，其存在不构成对本不变量"一级相态空间仅三态"原则的违反。

## 第三部分：准入协议 / Gatekeeper Protocol

新概念/补丁提炼时，必须依序通过以下五步准入审查：

1. **【既有覆盖问】**：该现象是否可通过既有 $M_1/M_2/M_3$ 或现有 Level 2 机制完全解释？➔ 若 YES：拒绝新增，判定为"无需更新字典"。
2. **【指标替代问】**：该概念是否仅仅是经验观察或测量方式上的差异？➔ 若 YES：降级归入 Level 3 经验指标。
3. **【因果创新问】**：该概念是否揭示了新的因果反馈路径，且不破坏"三大内生稳定来源"公理？➔ 若 YES：允许作为 Level 2 子机制提案。
4. **【独立验证问】**：该概念是否有多个相互独立的经验案例支持？➔ 若 NO：隔离登记为**临时观察（Observation）**。
5. **【理论收益问】**：该扩展是否显著提高了理论的解释力与可证伪性？➔ 若 NO：拒绝升级。

## 第五部分：治理与系统性约束 (Governance & Systemic Constraints)

### 5.1 非线性耦合规则（六组双向耦合关系）

$M_1, M_2, M_3$ 之间存在六组双向耦合关系，构成一个强化网络，稳定性作为涌现性质从中生成，**不可通过分解各机制独立贡献后加总获得**：

**稳定性生产侧**：
- $M_3\to M_2$：个体化激励结构分化协调主体，强化原子化状态
- $M_2\to M_3$：高原子化压制不满聚合，保护 $M_3$ 有效性外观
- $M_1\to M_2$：合法性水平降低所需维持的强制密度
- $M_2\to M_1$：原子化压制替代性叙事传播，保护官方叙事相对垄断
- $M_3\to M_1$：可观测资源分配为绩效叙事提供经验佐证
- $M_1\to M_3$：合法性叙事为选择性分配提供正当性框架

**脆弱性传导侧**：同一批通道在任一端点开始衰减时，以同等结构强度传导脆弱性而非稳定性——三对关系一旦任一方进入衰减区间，即由相互强化转为相互拖累。

**关键非线性命题**：当 $M_2$ 的控制效能 $\Phi(t)$ 趋近于零时，$M_1$ 和 $M_3$ 的贡献之和无法在阻止级联触发概率超线性上升的意义上弥补控制效能的缺失。此命题的对象是级联触发概率，而非 $\Psi(t)$ 本身——若将 $\Phi(t)=0$ 代入 $\Psi(t)$ 定义式，$\Psi(t)$ 在数学形式上仍可能因 $L(t)$、$B(t)$ 足够大而维持正值，这一线性代数事实与上述命题并不矛盾。

### 5.2 衰减动态（三条内生腐蚀路径）

| 路径 | 机制 |
|---|---|
| $M_1$ 棘轮效应 | $L_{perf}$ 与 $L_{sec}$ 切换具有单向阀效应；$L_{perf}$ 净损耗且难以恢复，形成不可逆信任折现 |
| $M_3$ 中间态积累 | $\Delta M3_{eff}(t) = N_{absorb}(t) - N_{aspirant}(t) < 0$；供给不足但退出成本仍高的隐性不满存量持续积累，且不被现有可观测指标捕捉，构成系统性低估区间 |
| $M_2$ 选择性强制饱和效应 | 累积处置频率 $F_{M2}(t)$ 超过饱和区间后，$D(t)$ 增长速率趋近于零 |

**时间轴重合命题**：三条腐蚀路径的加速激活期，与 $M_3$ 面临最大财政供给压力的历史阶段存在结构性重合，构成系统脆弱性积累速度加快的机制基础。此命题具有明确可证伪边界：若经验观测显示三条路径时间轴不重合，或重合区间与 $M_3$ 财政压力峰值缺乏系统性关联，命题即告证伪。

### 5.3 AI / Agent 运行边界（严格约束）

Agent 在调用本框架进行分析、预警或写作时，必须遵守以下边界，违反即视为超出框架认识论许可范围：

1. **禁止绝对测量断言**：所有诊断/预警读数只提供历史基准下的相对排序，不得解读为绝对脆弱性水平或概率数值。
2. **禁止时点预测**：不得对锚点位移型触发事件或任何离散触发事件的具体发生时点作出预测——此为认识论边界而非数据缺口。
3. **禁止解出方向概率分配**：系统进入 $S_3$ 分岔区间后，不得在"回归 $S_1'$／固化更深 $S_2$／结构性重组"三种解出方向之间分配概率。
4. **单指标不独立触发预警**：任一诊断指标进入警戒状态，不得独立构成预警升级，须至少两项相关指标联合背离方可诊断。
5. **禁止跨案例参数移植**：机制腐蚀速率参数（$\delta_S, \lambda, \gamma$ 等）具有案例特定性，不得未经独立案例内验证直接移植至其他分析对象。
6. **框架适用范围排除**：本框架不适用于——存在真实竞争性选举约束的政体；不具备数字化精准画像与算法去政治化能力的前数字化历史案例；军事权威结构主导、$M_1$–$M_3$ 功能分工从根本不同于党政科层体制的军事主导型政权。
7. **代理指标低估偏向的处理**：$\kappa(t)$ 相关代理指标存在系统性低估偏向（真实水平高于测量值这一方向确定，但偏向幅度不可精确估计），解读时应作保守上调，但不得将上调幅度机械量化为具体数值。
