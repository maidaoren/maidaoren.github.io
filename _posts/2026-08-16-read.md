# M1：合法性与叙事建构机制

威权统治要实现长期稳定，仅凭物理层面的强制M2与物质利益的收买M3远远不够——统治者必须建立并维持一套解释体系，以说明服从的正当性、资源分配的合理性以及控制手段的必要性。M1承担的正是这套政治解释系统的建构、内化与动态维系任务。

M1 由四个功能各异但紧密协同的组件构成：**L_perf**（绩效合法性）、**L_hist**（历史连续性引用）、**L_sec**（安全叙事与制度规训）以及 **L_inst**（认知规训机制）。四者并非平行并列的孤立模块，而是呈现出**层层嵌套、相互支撑**的结构：前三者（L_perf、L_hist、L_sec）提供具体的叙事内容与正当性话语；第四者（L_inst）作为元认知层，决定受众解读和评估前三者内容时所采用的底层框架。它们共同产出的合法性存量 $L(t)$，为 M2 的控制行为和 M3 的资源分配提供不可或缺的“意义正当性”背书。

```
                  ┌──────────────────────────────────────────────┐
                  │          L_inst (元认知与制度规训)              │
                  │  决定受众评估前三者内容时所使用的底层认知框架       │
                  └──────┬──────────────────────┬────────────────┘
                         │                      │
          ┌──────────────┴───────┐       ┌──────┴───────────────┐
          │ L_perf (绩效合法性)   │       │ L_sec (安全与威胁叙事) │
          │ 依赖当期治理产出/数据  │       │ 建构内外威胁/规训权力 │
          └──────────────┬───────┘       └──────┬───────────────┘
                         │                      │
                         └───────┐      ┌───────┘
                                 │      │
                          ┌──────┴──────┴──────┐
                          │ L_hist (历史连续性) │
                          │ 跨期象征资本/使命继承│
                          └────────────────────┘

```

### 1.1 L_perf：绩效合法性及其断崖效应

**L_perf（绩效合法性）** 依托于最直观的正当性来源：经济增长、大规模基础设施建设、公共服务改善以及贫困消除等可量化、可被公众在日常生活中直接感知的治理产出。这类合法性的建构成本相对较低、说服效率极高——当官方统计数据与个人的日常微观经验基本吻合时，叙事本身不需要复杂的意识形态包装，治理成果本身即可“自我证明”。

但这种高效的说服机制伴随着深刻的结构性脆弱性：

1. **零储备特性与即期兑现压力**：L_perf 缺乏独立于当期治理表现之外的长期价值储备。一旦经济进入结构性停滞、财政收缩或公共服务质量下滑，L_perf 无法凭空维持，只能随客观绩效的恶化而同步缩水。


2. **非线性断崖式崩塌（Discontinuous Collapse）**：L_perf 的衰减并非随客观经济指标的下滑而呈线性递减，而是呈现出明显的**临界点（Tipping Point）断崖效应**。当官方统计数据与公众的直接生活感知出现系统性落差（Systemic Discrepancy）时，公众对绩效叙事的信任不会缓慢打折，而会在跨过心理阈值后经历突发性的信任断裂。这意味着 L_perf 的失效往往与宏观经济指标不同步：它可能在经济数据尚未全面走弱前，因某起标志性的可信度危机（如公共卫生事件或重大安全事故中的信息瞒报）而提前破裂；也可能在经济长期低迷下，因缺乏“戳破幻象”的锚点事件而维持着表面的完好。



**与 M3 的互动及归因转变**：
L_perf 与 M3（资源与激励分配）存在强耦合的相互印证关系：M3 的物质资源分配为 L_perf 提供了日常层面的经验佐证；反之，当 M3 的资源再分配能力受挤压时，L_perf 的物质基础便随之松动。

在私人不满的生成路径中，L_perf 扮演着双向角色：

* 当治理产出、个人体验与官方归因高度一致时，L_perf 能有效将私人困境消解为“个人运气”或“市场波动”，压制不满走向政治化。


* 一旦三者之间出现持续且显性化的裂缝，L_perf 会发生**功能逆转**——曾经高度宣扬的“集中力量办大事”或“全能政府”承诺，反而成为推动公众将个人困境向体制性归因（Systemic Attribution）转向的核心诱因。

### 1.2 L_hist：历史连续性引用与象征资本

与押注于当期表现的 L_perf 不同，**L_hist（历史连续性引用）** 采用的是跨期资本化策略：将现任权威嵌入某种具有宏大历史使命或长期发展轨迹的叙事中，将其塑造为特定历史进程（如民族复兴、革命传统）的正当继承者，以此借用过去积累的象征资本。

L_hist 的核心优势在于提供**跨期缓冲能力**：在经济遭受阶段性挫折或外部环境恶化时，L_hist 能够填补 L_perf 留下的正当性赤字。它将当下的苦难解释为“长征路上的暂态”或“复兴必然经历的阵痛”，从而拉长受众评价统治正当性的时间窗口。

**比较基准与参照系区分**：
L_hist 的运作依赖于对历史比较基准的操纵——例如“比改革开放前强得多”或“摆脱了近代百年的屈辱历史”。**必须严格区分 L_hist 中的历史参照系与后文提及的外部/跨境参照系（R_fake/R_real）**：

* **L_hist** 属于纵向的、时间轴上的本国历史比较，通过控制历史记忆与叙事节点来维持；
* **境外参照系** 则是横向的、空间轴上的跨国治理比较。两者虽然都遵循“操控比较基准而非编造绝对事实”的逻辑，但触发机制与受损后的修复成本完全不同。



**非对称脆弱性（建慢塌快）**：
L_hist 的脆弱性来自两个方向：

1. **历史非虚构事实的穿透**：一旦官方历史叙事所掩盖的关键历史事实被广泛传播并引发公开讨论，整套历史连续性话语的内部逻辑链条将遭遇根基性的解构。


2. **精英阶层的公开路线分裂**：L_hist 默认历史继承过程具有无缝的合法性，若顶层精英在历史评价或发展路线（如“两个三十年”的关系）上出现公开分歧，这一默认的前提将被瞬间否定。



L_hist 表现出极强的**非对称结构特性**：几十年持续的教育与宣传才能积累起微弱的历史认同（“建得慢”），但某个突破审查的历史真相或精英分裂事件，足以在极短时间内使这几十年的储备彻底归零（“塌得快”）。

### 1.3 L_sec：安全叙事、威胁建构与制度规训

**L_sec（安全叙事与制度规训）** 走的是第三条路径：通过建构外部威胁（如敌对势力渗透、意识形态演变）与内部威胁（如社会动荡、秩序失序），来论证现有统治安排与高强度控制的不可替代性。它将治理上的限制重新编码为“安全所必需”，将强制与监控包装为“对社会的安全保护”。

与 L_perf 相比，L_sec 的建构空间更大，因为它不完全取决于客观威胁的真实存在与大小，而取决于威胁在认知上的**显著性（Salience）**。但这套机制受到严苛的动态规律约束：

#### 威胁通货膨胀与边际效用递减

L_sec 的说服效力随着其被激活的频率上升而加速衰减，这一现象被称为**威胁通货膨胀（Threat Inflation）**。其数学模型表达为：

$$\text{Effectiveness}(L_{sec}) = \eta_0 \cdot \exp(-\lambda \cdot F_{sec}(t))$$

其中 $\eta_0$ 为初始安全叙事效力，$\lambda > 0$ 为公众脱敏系数，$F_{sec}(t)$ 为截止到时间 $t$ 安全叙事被激活的累计频率。

```
Effectiveness(L_sec)
   ^
η₀ │───┐
   │    \
   │     \   (衰减曲线：高频使用导致心理脱敏)
   │      \
   │       └───> 趋近于 0
   └───────────────────────────> F_sec(t) (激活频率)

```

每次激活安全叙事（如将社会抗议归咎于外部势力），其边际说服力都低于上一次。当激活频率跨过受众的**心理脱敏临界点**时，边际效用呈指数级下滑，最终趋近于零。L_sec 是一种**非可再生型储备**：使用越频繁，剩余的可用正当性空间就越小。

#### 间接功能与规训同构

1. **为 M2 的选择性强制赋权**：当 L_sec 成功将特定群体定性为“安全威胁”后，M2 针对该群体的监控与处置不再被大众视为对权利的侵犯，而被重新解释为“必要的国家防护”，从而大幅降低 M2 的社会抵触成本。


2. **与规训权力（Disciplinary Power）同构**：传统权力依赖于强制的可见性以制造威慑；L_sec 促成的规训权力恰恰相反——国家强制本身趋于隐形，而被规训的个体被置于一种“持续被观察、但无法确认具体时刻”的状态中，从而促成个体的自我审查与自发合规。


3. **注意力转移战术及其反噬**：当负面治理事件爆发时，体制常通过放大低敏感度热点进行情绪分流。这套战术同样遵循边际效用递减规律：当受众摸清这一套路后， sudden 冒出的娱乐热点反而会被解读为“必有重大负面事件被压下”，使注意力转移工具反向转化为引发公众怀疑的催化剂。

### 1.4 L_inst：认知规训机制与元认知框架

前三个组件（L_perf、L_hist、L_sec）属于**叙事内容层**，回答“为什么相信”的具体理由；**L_inst（认知规训机制）** 则完全不同，它是**生产与筛选这些内容的“元认知机器”（Meta-cognitive Architecture）**，是 M1 中性质最特殊、影响最深远的核心组件。

```
┌──────────────────────────────────────────────────────────┐
│                   L_inst (元认知框架)                     │
│  [科层化政治教育] [意识形态社会化] [组织生活] [日常娱乐渗透]  │
└──────────────────────────┬───────────────────────────────┘
                           │ 塑造底层预设
                           ▼
┌──────────────────────────────────────────────────────────┐
│                     受众解读系统                          │
│        决定如何评判 L_perf, L_hist, L_sec 的真实性        │
└──────────────────────────────────────────────────────────┘

```

L_inst 渗透于社会的深层结构：科层化的政治教育体系、贯穿幼年到成年的意识形态社会化、强制性组织生活、档案政治评价记录，以及嵌入日常文化消费的底层隐喻。它旨在将统治秩序内化为个体理解政治现实时不假思索采用的**默认预设（Default Presupposition）**。

#### L_inst 的三大根本特征

1. **高跨周期稳定性**：几十年的社会化塑造积累的认知框架，不会因短期的经济波动或单一政策失误而轻易动摇，是 M1 中最稳定的资产。


2. **结构性主导作用**：它不提供具体政策的解释，而是决定受众使用什么样的逻辑去评估 L_perf 的数据、L_hist 的真实性与 L_sec 的威胁。


3. **代际传递与修复制约**：其效力通过教育与家庭结构逐代延续，但这也意味着一旦遭遇系统性破损，其修复将耗费数代人的时间，极难在短期内重建。



#### 破坏力与双重衰减路径

由于其元认知性质，L_inst 的崩塌将带来去魅（Disenchantment）与认知震荡：受众失去的不是某个具体说法，而是长期借以理解社会现实的整套参照系，从而引发全局性的政治信仰瓦解。

除突发性崩溃外，L_inst 存在一条**内生衰减路径——“自我僵化”（Self-Ossification）**：

* **区别于受众端的“棘轮效应”**：受众端棘轮效应处理的是受众信任折价的不可逆性；


* **生产端的自我僵化**：描述认知框架因长期处于无竞争环境而丧失自我调适与演化能力的过程。当一种意识形态消灭了所有有质量的竞争性论述后，其内部精细化与动态修正的张力随之消失，最终退化为语词僵硬、脱离现实生活的教条。这导致其在面对新型社会矛盾时，无法提供具备说服力的解释方案。



#### 溢价效应与领袖人格化占比 $M_{1\_person}(t)$

L_inst 能为其成员提供超出物质回报的“精神溢价”与使命感：

* 当 L_inst 运转良好时，即便 M3 提供的物质激励因财政紧缩而打折，体制内成员的主观效用仍能维持，因为身份的“意义溢价”弥补了物质折价。


* 若 L_inst 遭遇去魅或僵化，这份溢价迅速消退，M3 的激励效果将彻底回归其纯粹的市场价格，大幅推高体制的维系成本。



为定量捕捉 L_inst 的衰减与合法性基础的变化，引入**叙事集中度指标 $M_{1\_person}(t)$**：

$$M_{1\_person}(t) = \frac{\text{叙事中对最高领导人的人格化引用文本量}}{\text{基于制度/机构/规则的正当性话语文本总量}}$$

$M_{1_person}(t)$衡量的不是权力集中本身，而是合法性基础对“当期可感知成就与个人威望”的依赖程度。靠非人格化制度运转的威权体系，对绩效波动具有较强的免疫力；而 $M_{1\_person}(t)$ 越高，正当性越绑定于单一领袖的无误性（Infallibility）。一旦遭遇重大政策失误或领袖威望受损，总合法性 $L(t)$ 将面临极高的结构性脆弱风险。

### 1.5 参照系建构

L_perf、L_sec 与 L_inst 在操作底层共享同一种核心技术：**参照系建构（Reference Frame Construction）**。其核心逻辑不是直接篡改第一手事实，而是操纵受众评估现实状况时所采用的**比较基准（Benchmarking）**。

定义两组受众认知中的参照系集合：

由国家宣发机器主动建构、持续推高其显性度与显著性的比较对象集合（如特定西方国家的治理乱象、历史上的灾难时期）。

经由非官方或非受控渠道（如跨境交流、互联网、真实国际排名）流入受众认知，但未被官方主动纳入的比较对象集合。



```
                        ┌────────────────────────┐
                        │    治理失误/感知落差     │
                        └───────────┬────────────┘
                                    │
                    ┌───────────────┴───────────────┐
                    │  受众调用的评估参照系 (尺子)    │
                    └───────┬───────────────┬───────┘
                            │               │
                            ▼               ▼
                   ┌────────────────┐ ┌────────────────┐
                   │  R_fake(t) 占优 │ │  R_real(t) 占优 │
                   └────────┬───────┘ └────────┬───────┘
                            │                  │
                            ▼                  ▼
                   ┌────────────────┐ ┌────────────────┐
                   │ "虽有瑕疵但整体良好"│ │ "体制性/结构性问题"│
                   └────────────────┘ └────────────────┘

```

#### 参照系生产的操纵机制与分层供给

体制介入参照系的方式分为**被动渗透**（信息自然流入）与**策略性主动生产**（通过外交活动、多边倡议、对外援助来提升特定比较对象的显影度）。体制无法完全伪造事实的真实性，但可以通过控制媒介来极大地操纵事实的**显著性（Salience）**。

参照系在社会结构中呈现明显的**分层供给**特征：

* **大众层**：高度依赖官方供给的 $R_{fake}(t)$，斗争与批判阈值较高。


* **中产与精英层**：具备较高的信息获取能力，倾向于使用国际专业标准 $R_{real}(t)$，对治理失误的容忍阈值较低。


* **意见领袖与具象中介**：海外意见领袖或跨国中介人物的核心价值，在于降低了普通人验证 $R_{real}(t)$ 的认知成本，赋予了外部参照系以情感穿透力，从而加速受众认知中参照系的替换。



当 $R_{fake}(t)$ 主导时，社会不满多转化为内部存量竞争（“内卷”）；而当 $R_{real}(t)$ 显著上升并占据主导时，社会不满将直接指向治理范式本身。参照系的转换期往往伴随着可信度的结构性真空，其衰减同样遵循边际效用递减的规律。

### 1.6 M1 总产出函数 $L(t)$ 与权重动态演化

将四个组件的贡献汇总，M1 在时间 $t$ 产生的总合法性/服从正当性产出可表示为：

$$L(t) = \alpha_1(s) \cdot L_{perf}(t) + \alpha_2(s) \cdot L_{hist}(t) + \alpha_3(s) \cdot L_{sec}(t) + \alpha_4(s) \cdot L_{inst}(t)$$

其中权重向量 $\vec{\alpha}(s) = [\alpha_1, \alpha_2, \alpha_3, \alpha_4]$ **并非常数，而是随体制的治理状态 $s \in \{S_1, S_2, S_3\}$ 发生结构性重分配**：

1. **常态治理状态 ($S_1$)**：$\alpha_1$ 占据绝对主导地位，绩效叙事（$L_{perf}$）是合法性的主要来源，体系维持低成本运转。


2. **强化治理状态 ($S_2$)**：随着绩效边际递减，$\alpha_3$（安全叙事）与 $\alpha_4$（认知规训）的权重被强制推高，以弥补 $\alpha_1$ 的下滑。


3. **愿景驱动型强化治理（特别形态）**：$L_{hist}$ 的功能发生前瞻性扩展——它不再仅仅援引过去的历史连续性，而是承担起通常由 $L_{perf}$ 承担的功能，为受众提供一个“尚未兑现但被承诺即刻实现”的宏大转型愿景（如“大跃进”时期），以此在前瞻层面上替代当期 $L_{perf}$ 的角色。



**关键认识论修正**：
$L(t)$ 测量的是受众在公共空间中**可观察的合规行为与公开表达（Compliance and Public Conformity）**，而非私人内心深处的“真正认同”。$L(t)$ 的稳定甚至上升，可能仅代表偏好伪装（Preference Falsification）的加深，绝不可被直接等同于体制真实认同基础的扩大。

### 1.7 M1 的内生腐蚀动力学：单向阀与棘轮效应

M1 系统内部存在一套不可逆的自我腐蚀机制，其核心在于 **$L_{perf}$ 与 $L_{sec}$ 之间切换的“单向阀效应”（One-way Valve Effect）**。

graph TD
  A["L_perf (绩效叙事) 破裂"] --> B["(短视应对: 提升安全权重)"]
  B --> C["L_sec (安全叙事) 权重上升"]

1. **单向阀切换**：当 $L_{perf}$ 因经济下滑出现裂缝时，统治者习惯性地提升 $L_{sec}$ 的权重来填补正当性赤字。


2. **纠错机制的毒化**：$L_{sec}$ 的逻辑要求将对绩效失败的批评定性为“安全威胁”或“外部颠覆”。这一定性系统性地清除了本可充当早期预警信号的社会异见与反馈。


3. **棘轮效应（Ratchet Effect）的形成**：安全叙事的过度依赖破坏了体制进行政策自我修正的制度条件，使得未来即便经济微弱复苏，也无法重新补充 $L_{perf}$。



这种切换构成了不可逆的**棘轮过程**：叙事转换过程中的信任折价无法被逆转。随着 $L_{perf}$ 陷入净损耗、$L_{sec}$ 加速遭遇威胁通货膨胀，总合法性 $L(t)$ 将不可避免地进入结构性下行轨道。

同时，$\mathbf{L_{inst}}$ **衰减对私人不满生成效率的间接影响**：
在 $L_{inst}$ 掌控力强盛期，个体倾向于将个人挫折归因于“个人运气不好”或“局部官僚腐败”（归因门槛极高）；而随着 $L_{inst}$ 因棘轮效应与自我僵化而衰减，这道认知屏障随之坍塌，相同的客观遭遇（如失业、断供）将以极高的效率直接转化为针对体制本身的**系统性归因（Systemic Attribution）**。这构成了 M1 自我腐蚀进而引发系统脆性积累的另一条关键间接路径。

## M2：控制与原子化机制

在威权韧性更新的理论架构中，M2 占据着绝对的系统枢纽地位。它并非两个独立目标的简单并列，而是由一个**核心功能**（组织原子化）与一个**强化子模块**（选择性强制）共同构成的统一控制体系。

其核心逻辑在于：**组织原子化**旨在切断个体之间的横向社会联结，系统性地阻断私人不满向可识别集体压力的转化；**选择性强制**则通过精准威慑，强化原子化状态在持续社会压力下的稳定性。

两者形成了一种极其紧密的支撑关系：组织原子化为选择性强制创造了低成本运作所需的社会隔离条件——孤立的个体极难形成有效的集体声援，使处置行动的连带政治成本降至最低；选择性强制反过来为组织原子化提供了持续更新的威慑基础——个体的任何横向协调尝试都面临被系统识别和精确处置的感知风险，使原子化状态在高压条件下得以自我维持。

### 核心功能：组织原子化 $A(t)$

私人知识向公共知识的转化，在结构上不是单纯的信息传播问题，而是一个**协调问题**。个体之所以长期在公开表达与私人评估之间维持巨大落差，是理性计算而非认知障碍的产物——只要无法确认他人与自己持有相同的不满，横向协调的预期成本便会持续超过预期收益。

组织原子化的三条路径，各自从不同层次攻击私人知识向集体协调转化所需的基础条件：

1. **宏观组织基础设施层**：通过对社会组织施加系统性的注册合规负担，在私人不满积累之前预先清除聚合为集体叙事所需的组织容器。这一逻辑同样适用于体制自身提供的正式诉求渠道——以个案受理、个案转办为基本处理单位的申诉制度，即便形式上开放了诉求表达的合法途径，只要不为具有相似遭遇的申诉人提供任何识别彼此、确认诉求普遍性的机制，就从功能上复现了同一条阻断逻辑。
2. **中观信息生态层**：以重定向而非简单粗暴的审查删除为核心机制，系统性降低跨地域、跨议题协调信号在数字平台上的社会可见性，将信息流引向娱乐消费与个人生活领域。这一路径的成本效益远高于直接审查：它不需要识别并处置每一条可能触发协调的内容，而是通过改变整体信息生态的结构性形态，来降低协调信号的传播概率。
3. **微观行为预期层**：通过将治理空间切分为可管理的最小单元并部署信息收集节点，制造无处不在的被观察感，在集体行动萌发阶段就改变个体的行为预期。其运作机制是概率性而非确定性的——不需要实际捕获每一个尝试将私人知识公开表达的个体，只需维持被发现的感知概率足以使预期成本超过预期收益即可。

三条路径的互补性体现在层次覆盖的完整性：宏观层拆除组织容器，中观层阻断信息流通网络，微观层压制行为表达意愿。然而，三条路径存在共同的内生局限——它们能够显著提高私人知识转化为公共知识所需跨越的门槛，但**不能阻止私人知识本身的形成**，也不能阻止个体在信任网络（如家庭、紧密的私人关系）内部的横向知识传递，因为原子化的技术与制度设计主要瞄准的是陌生人之间的协调。

$A(t)$ 的功能范围还有两处关键扩展：

* **对中间层级行动者的防范**：原子化不仅压制大众个体，也适用于防止中间层级行动者（地方官员、安全机构负责人、掌握独立资源的私人行动者）把体制授予的执行权限或资源支配权转化为独立于中央的私人权力基础。若中间层级行动者能够便利地建立横向联结，其手中的授权就存在向独立权力基础转化的空间。
* **对未来替代方案的提前清场**：常态时期对社会自主组织能力的持续压制，不仅阻断当期的集体行动协调，也同时抑制了任何可能在未来危机中充当替代性重建方案的组织与意识形态雏形的孕育空间。这一效应在危机解出方向上具有深远的影响。

### 强化子模块：选择性强制及其委托—代理基础

选择性强制通过大规模数据画像和个体化处置，将强制手段从传统的劳动密集型、批量化模式，重构为资本密集型、精准个体化的全新模式。精准画像技术允许系统识别具有高协调节点潜力的个体，将处置资源集中于最可能产生级联效应的行动者，在实现等同于批量化手段威慑效果的同时，大幅降低引发横向声援和连带反应的概率。

然而，这一机制的有效性并非由中央意志到基层执行之间的无损传导所保证。承担初级执行职能的基层人员并非中性的执行终端，而是拥有独立效用函数的行动者：他们对特定个体的政治敏感性拥有信息优势，同时在处置的具体方式和力度上保有相当程度的自由裁量权，其行为受创收、晋升等激励与有限问责的双重塑造。

这一代理损耗有两种典型表现形式：

* **形式主义化**：执行力度的消极衰减——执行者用能够通过考核、却不真正消耗太多精力的方式敷衍任务。
* **自利性扭曲**：执行方向的主动偏移。

两者共享同一种委托—代理张力，但作用方向不同：前者是“少做”，后者是“做偏”。

形式主义化并非单纯的能力不足或意愿缺失，而可以从策略选择的角度定位：当执行者面对上级指令与自身处境之间的落差时，其可用策略包含正式申诉与非正式协商两类；当这两类渠道因组织结构原因同时受限——正式申诉缺乏被采纳的制度保障，非正式协商缺乏可动用的关系资源——执行者剩余的可行策略集合便收窄至“表面服从、实质消极执行”这一单一选项。形式主义化因此不是执行者主动选择的最优策略，而是谈判空间收窄后唯一剩余的理性残余策略。

选择性强制的成本结构通过四个维度实现了高度的外部化：

1. **识别成本**：转嫁给被监控个体本身（其日常行为数据构成了精准画像的免费原材料）；
2. **基层执行成本**：部分转嫁给以低于市场水平薪酬工作的初级执行人员；
3. **审查操作成本**：通过合规义务转嫁给平台企业；
4. **基础设施终端成本**：转嫁给自行购置相关智能设备的消费者。

这一外部化结构使国家层面可见的直接统治成本维持在相对较低水平，使威慑—成本比 $D(t)$ 在外部化机制正常运转的条件下保持高位。

连坐性扩展进一步强化了这一机制：政治审查风险经由档案制度延伸至家庭成员的教育机会、就业前景与行动自由，将个体不合作的预期代价从个体本身延伸至最小社会单元。不合作预期成本（记为 $C_{defect}$）因此兼具**确定性**（由精准画像决定，非随机抽检）、**即时性**（处置通常在行为发生后短时间内启动）与**连带性**（延伸至家庭）三项特征，极大地提高了不合作决策的主观门槛。

### 基层执行的自利性扭曲：三种类型

基层执行人员的自利性扭曲超越了简单的执行力度衰减，构成执行方向本身的主动偏移，在实践中表现为三种主要的类型化机制：

1. **处置权的资产化**：查扣或没收的物品不经正式处置流程，而是通过非正式渠道流入市场变现。处置行为的名义功能（消除违规状态）与其实际功能（创造可变现资产）发生了严重的剥离。
2. **处罚裁量的隐性货币化**：对轻微或边界模糊的违规行为以罚款替代规范性管理，程序性凭证的系统性缺失使这类征收脱离了正常的财务问责链条。它与处置权资产化的区别在于：前者作用于“物的处分”，后者作用于“对人的处罚裁量本身”。
3. **目标选择的自利重排**：处置资源从算法层面确定的高协调节点目标，系统性偏移至缺乏申诉能力和抵抗资源的弱势群体。因为对后者的处置摩擦成本更低、创收效率更高。

这三种类型共同构成一种双重动机结构：**意识形态忠诚与实际利益攫取并存**。这为基层执行者提供了不同于象征性忠诚回报的实际经济激励，短期内维持了基层执行的高动员热情。

但其外溢后果也是双重的：一方面侵蚀了威慑效能 $D(t)$ 的名义精准度，使处置资源偏离原定的高价值目标；另一方面，这类处置结果在受众认知中往往伴随对执行公正性本身的严重怀疑，构成私人知识积累的独立来源——不同于对体制核心叙事真实性的私人评估，这是对执行公正性的私人评估，两者共享向公共知识转化的机制路径，但触发条件有所不同。

### 中央—地方—基层的共谋均衡

成本外部化并非单纯的财政技术安排，而是一种深层制度均衡的产物：不同层级的行动者以不同形式和程度参与其中，形成表面稳定、实质脆弱的共谋结构。这一均衡同时承担两种性质不同的功能——短期而言提供真实的稳定性收益（压低国家可见治理成本，为多方参与者提供可预期的既得利益分配格局）；长期而言持续积累系统性脆弱性（成本并未消失，只是以分散、延迟的形式转移至系统的其他部分）。

基层自由裁量权是这一均衡的结构必要条件，而非委托—代理损耗的偶然副产品：选择性强制作为专断权力的一种具体实现形式，其有效运作依赖专断权力能够逐级复制——最高决策层的任意裁量能力若要在庞大的执行链条中得以贯彻，每一级执行者都必须获得相应幅度的自由裁量空间，否则专断权力将在传导过程中被科层规则本身稀释为程序性权力。

地方治理主体是这一均衡的中枢传导者：通过默许甚至鼓励基层创收，在不显著增加财政支出的情况下维持控制强度，构成一种隐性契约。最高决策层则采取选择性干预策略：常规状态下容忍，出现重大显性风险信号时再进行针对性整顿，且整顿触发时点与显性风险信号强度的相关性通常强于其与违规客观严重程度的相关性——这类整顿具有仪式化特征，对外维持“有错必纠”的叙事，对内为成本外部化机制的持续运转提供合法性外衣。

共谋均衡内部的行为模式并非固定不变，而是随任务与评估周期所处阶段发生系统性轮换：

* **任务执行周期内部**：上级“选择性干预”与基层“层层加码”表面矛盾，实则可从控制权结构在不同阶段的分配差异中获得统一解释——任务执行阶段，检查验收权尚未启动，理性策略是向下传导压力，“层层加码”由此产生；检查验收阶段，暴露偏差的成本已经产生，理性策略转为与下级协同掩盖问题，“共谋”由此产生。
* **评估周期内部**：周期早期完成任务的压力主导；周期中段维系多方协作关系的考量上升；周期临近验收节点时规避暴露风险的考量重新占据主导。两个层次共同说明：共谋均衡在任一时点上呈现的具体面貌，很大程度上取决于该时点在其所处周期中的相对位置，而非仅由结构性激励强度决定。

均衡内部绑定的性质并不均匀：体制内的执行者及其家属绑定更接近资产积累型，职业身份与社会关系网络为其提供了隔离与申诉能力；均衡外部承受后果的普通民众——合同制雇员、非正规从业人员——绑定则依赖对稳定性供给的持续信任，缺乏这类隔离能力。稳定性供给承诺一旦出现可观测的违约迹象——且这类违约往往需要通过更高层级发起的专项治理周期性压回可控区间而非被根除——暴露的正是体制自身认定需要优先管控的脆弱环节，这意味着依赖稳定性供给绑定的人群，其私人知识积累速率存在快于依赖资产积累绑定人群的结构性理由。越接近基层层级，行动者对非正式渠道的依赖程度越高，正式谈判渠道的相对作用越弱——基层与上下级互动更频繁、场景更多样，非正式关系培育成本更低，正式申诉所需的证据基础与程序知识则获取成本更高。

这一均衡的脆弱性还有另一重来源：原子化程度的提升削弱了地方性非正式互助网络这类中间缓冲层，而这类缓冲层同时也是国家任务得以有效落地执行的必要投入条件。原子化因此存在自我抵消效应——它在阻断横向协调的同时，也在削弱地方执行任务所需的社会资本投入。这一状态具有内在双重性：常态区间，它是原子化机制运作有效性的体现；一旦特定触发事件同时触及大量个体的共同处境，缺乏中间缓冲层同样意味着缺乏吸收冲击的结构性余地，个体反应因此更可能在时间维度上高度同步。

中央—地方—基层围绕成本外部化形成的共谋均衡并非数字治理时代的全新产物，基层自由裁量权与地方默许所构成的隐性合谋结构早已存在，是科层委托—代理关系的普遍特征。技术条件改变的不是这一均衡的存在与否，而是其系统性与规模：更高效的识别技术为基层自利行为的目标选择提供了更高的效率基础，使原本依赖个体经验和地方人脉的非正式合谋，获得了更具规模化、可复制性的操作形态。

### 威慑—成本比 $D(t)$ 的复合结构与综合控制效能 $\Phi(t)$

威慑—成本比 $D(t)$ 由两个彼此独立作用的因素共同决定：

1. **因素一（选择性强制自身的边际效应递减）**：处置频率较高时，威慑效能随处置增加而上升；一旦超过饱和区间，效能的增长速率趋近于零，目标群体已将一定概率的处置风险内化为日常预期背景，心理脱敏机制随重复暴露加速运行。
2. **因素二（执行方向偏移对威慑效能的独立压制）**：基层自利系数（涵盖信息不对称与自由裁量权两个维度）随财政压力上升而上升；即便处置频率处于中等水平、饱和效应尚不显著，若基层自利系数已处于高位，威慑效能的实际水平仍可能显著低于饱和效应单独预测的水平。基层执行的形式主义化进一步加速这一落差：激励扭曲使初级识别延迟系统性高于算法理论响应速度，输入数据质量的下降等比例削弱精准处置精度。

综合控制效能可以用函数表示为 $\Phi(t) = f(A(t), D(t))$，用以捕捉两者的交互效应。两者的联合效应**高于线性加总**：原子化为精准威慑创造了最有利的执行条件（孤立个体无法形成集体声援，处置的连带成本趋近于零），精准威慑的存在又使原子化状态在持续社会压力下具备了自我维持的激励基础。

必须指出的是，$D(t)$ 与 $A(t)$ 在特定领域的实际强度，还受同一批执行行动者在其他不相关领域对治理对象合作依赖程度的影响——当执行者在领域甲需要依赖治理对象在领域乙的配合（如经济活动的正常运转、信息的及时上报）时，领域甲的控制强度即便名义不变，实际执行力度也可能因这一跨领域依赖而受到抑制。因此，某一领域观察到的控制强度变化，其成因未必内生于该领域本身。
