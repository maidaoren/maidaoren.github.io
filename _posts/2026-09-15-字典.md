# **Canonical Theory Ontology v1.0**

## **《全控治理模型核心理论本体与符号字典》**

版本性质：初始正式版本 · 核心定义依据：《想吃管：全控型治理模型》

# **第一部分　理论本体总结构**

## **1.1 理论研究对象**

全控治理模型研究国家权力如何通过政治意义建构、资源依附和组织控制，影响社会成员的认知、生计、组织关系与行为选择，并进一步改变社会组织结构、社会心理、行为适应和长期社会能力。

模型的基本政治关系是**非对称服从交换**。

国家通过规则制定、资源配置、组织管理和制度处分维持社会成员的行为配合；社会成员通过遵守制度规则、履行组织义务和调整自身行为，获得公共秩序、安全保障、公共服务、身份资格、资源供给与发展机会。

服从交换不是平等协商的政治契约，其关键特征是权力、资源配置和退出能力存在不对称。

## **1.2 核心理论层级**

| 层级 | 理论对象      | 核心内容                              |
| -- | --------- | --------------------------------- |
| L0 | 总体政治关系    | 非对称服从交换                           |
| L1 | 治理机制      | M1、M2、M3                          |
| L2 | 状态变量      | Q、K、F                             |
| L3 | 内部机制与中间概念 | 子模块、作用过程、组织结构、认知过程、反馈环节           |
| L4 | 治理状态      | S1、S2-D、S2-O、S2-V、S3              |
| L5 | 第二层社会后果   | 社会组织结构、社会心理、行为适应、人格倾向、代际传递、社会能力变化 |

**层级原则：**

- M1、M2、M3是治理机制，不是状态变量。
- Q、K、F是状态变量，不是治理机制。
- S1、S2、S3是治理状态，不是新的治理机制。
- 第二层内容是治理机制长期作用下形成的社会结构与人格后果，不应直接与第一层机制混为一谈。
- 中间概念用于解释机制和状态之间的作用过程，不应自动升级为独立变量。

# **第二部分　核心治理机制**

## **2.1 M1：政治意义建构与现实解释机制（想）**

**正式定义**

M1是政治意义生产与现实解释机制，指政治权力通过政治叙事、正当化来源、制度化传播、社会化、规范化认知、归因框架和参照系建构，生产并传播解释政治秩序的意义结构，组织现实解释、责任判断和制度评价。

其核心功能是为政治秩序提供意义与正当化理由，并塑造社会成员理解政治现实所处的公共解释环境。

**研究对象**

- 政治意义如何生产；
- 合法性来源如何组织；
- 政治叙事如何传播；
- 现实问题如何被解释；
- 功绩与责任如何归属；
- 社会现实如何被比较和评价；
- 既有叙事如何修补及衰减。

### **2.1.1 四类合法性来源**

| 符号     | 标准名称        | 正式概念  | 核心内容                                           |
| ------ | ----------- | ----- | ---------------------------------------------- |
| L_perf | 绩效合法性       | 绩效合法性 | 通过经济发展、就业改善、收入增长、公共服务和生活条件改善等可感知成果提供正当性依据      |
| L_hist | 历史合法性（历史道统） | 历史合法性 | 通过历史继承、革命起源、建国叙事、民族历史和共同体使命提供历史正当性依据           |
| L_sec  | 安全合法性       | 安全合法性 | 通过国家安全、社会稳定、共同体保护和风险防范，将现存制度解释为避免重大威胁的必要条件     |
| L_inst | 制度化认知       | 制度化认知 | 通过教育、媒体、文化生产、公共仪式、组织表达和家庭社会化，使政治意义获得持续传播和社会化基础 |

四类来源具有不同的正当化基础，可以相互补位，但不能相互替代。

其中：

- L_perf依赖现实治理成果；
- L_hist依赖历史事实、历史解释和共同体记忆；
- L_sec依赖风险识别、威胁解释和秩序保护；
- L_inst依赖政治意义的长期传播、分类和社会化。

L_inst不等同于法治合法性、程序合法性或制度绩效。

### **2.1.2 归因框架**

**归因框架**是M1组织现实解释的重要机制，指政治权力通过选择和组织因果关系、责任层级、功绩归属、失败责任和解释范围，影响社会成员理解现实问题及其成因的方式。

主要内容：

- 因果选择与因果组织；
- 归因层级与责任类型；
- 功绩归属与失败责任分配；
- 归因方向与解释范围；
- 解释竞争与归因可信度。

归因框架影响现实问题被解释为个人、组织、政策、制度或外部环境问题的方式。

它不等同于事实本身，也不能代替因果识别。

### **2.1.3 RFP：参照系建构**

Reference Frame Production

**正式定义**

RFP是M1内部组织现实比较与评价的重要机制，指政治权力通过选择、组织和突出比较对象、评价标准、时间与空间尺度及其解释关系，影响社会成员理解现实表现和评价政治秩序的认知条件。

**五个基本维度：**

1. 比较对象：国家、地区、历史时期、制度、发展阶段和社会群体。
2. 评价标准：经济、收入、秩序、公共服务、权利、安全、公平等。
3. 时间尺度：短期、中长期、代际和历史尺度。
4. 空间与社会尺度：国家、地区、城乡、行业、职业和阶层。
5. 解释关系：比较结果如何被组织为关于制度、政策和治理能力的因果解释。

**理论边界：**

- RFP研究政治权力如何组织比较条件。
- K研究社会成员实际接触、采用和形成何种参照系。
- 比较结果不等于因果结论。
- 官方参照系不必然虚假，替代参照系也不必然真实。
- 参照系传播不等于社会成员已经接受。

### **2.1.4 领导人人格化合法性**

领导人人格化合法性是政治叙事围绕最高领导人的个人形象、政治判断、治理贡献、历史地位和象征意义组织表达，使领导人成为政治秩序、国家发展、历史使命和共同体未来的集中象征。

它不是第五类合法性来源，而是L_perf、L_hist、L_sec、L_inst四类来源向具体领导人集中的特殊形式。

必须区分：

- 领导人人格化合法性：意义与象征结构；
- 实际权力集中：政治权力结构；
- 公开崇拜表达：公共表达形式；
- 私人认同：社会成员的内部判断。

### **2.1.5 叙事修补与合法性衰减**

**叙事修补**是政治权力在现实经验与既有政治解释发生冲突时，通过调整因果归属、责任层级、解释范围、比较标准和意义关系，重新组织现实解释的动态过程。

主要形式：

- 归因调整；
- 解释范围调整；
- 因果关系调整；
- 时间与空间尺度调整；
- 合法性来源之间的解释补位；
- 知识分类与现实可见性调整；
- 参照系转换。

**合法性衰减**是政治秩序原有正当化依据的可信度和解释能力受到持续侵蚀的过程。

叙事修补可以缓冲合法性压力，但不能直接创造现实绩效，也不能保证社会成员接受新的政治解释。

## **2.2 M2：资源依附与退出约束机制（吃）**

**正式定义**

M2是全控型治理中的资源依附与退出约束机制，研究个人、家庭及私人组织在获得和维持生存、发展与经营所需资源的过程中，如何因关键资源渠道集中、供给条件受制于不对称权力关系、替代渠道不足以及退出成本较高，而形成持续性资源依附，并由此受到行为约束。

M2构成服从交换的物质基础。

**核心问题：**

- 资源由谁提供；
- 资源如何分配；
- 资源依附如何形成；
- 资源关系如何维持；
- 行动者能否通过替代和退出获得实际自主性。

M2不是资源数量、经济增长或一般经济依赖的同义词。

### **2.2.1 M2-a：身份资产型依附**

**正式定义**

身份资产型依附，是指个人及其家庭因长期积累的身份、资格、职业发展和关系资源与特定组织或制度渠道绑定，在离开原有身份关系时面临多项资源损失，从而形成持续性资源依附。

\*\*绑定基础：\*\*过去积累而难以整体带走的身份资产。

**主要资产类型：**

- 直接经济资产；
- 制度资格资产；
- 职业发展资产；
- 关系与声誉资产；
- 家庭及代际资产。

**主要作用过程：**

身份资格与资源绑定 → 长期积累 → 沉没资产形成 → 退出成本上升 → 行为约束。

### **2.2.2 M2-b：生活供给型依附**

**正式定义**

生活供给型依附，是指个人及其家庭在维持基本生活、稳定消费和长期发展时，对持续性收入、住房、公共服务及其他生活资源形成依赖，而这些资源的获取和维持受到不对称制度关系、渠道集中和替代不足的约束。

\*\*绑定基础：\*\*未来持续供给。

**主要领域：**

- 就业与劳动收入；
- 住房及家庭生活供给；
- 资产与债务；
- 公共服务与身份准入；
- 家庭再生产与代际转移。

**主要作用过程：**

持续生活需求 → 资源渠道集中 → 替代渠道不足 → 供给中断风险 → 行为约束。

### **2.2.3 M2-c：私人资本型依附**

**正式定义**

私人资本型依附，是指私人企业、私人资本及其经营者在生产、投资和经营中，对融资、土地与场所、行政许可、市场准入、政府采购、税费与行政成本、供应链、技术、产权保护等条件形成的依赖。

当关键经营资源集中于少数不可替代的渠道，资源准入、延续与保护受到不对称权力关系支配，而企业缺乏替代与退出能力时，普通经营依赖便可能转化为结构性或制度性依附；当这种依附进一步与政治关系、行政裁量或选择性风险处置发生系统性联系时，则具有政治性。

\*\*绑定基础：\*\*当下已经投入经营、暴露于制度规则与风险之下的私人资本。

**主要领域：**

- 融资；
- 土地与经营场所；
- 行政许可与市场准入；
- 政府采购；
- 税费与行政成本；
- 供应链；
- 技术；
- 产权保护；
- 经营风险与保护预期。

### **2.2.4 M2共同概念**

| 概念     | 定义                                          |
| ------ | ------------------------------------------- |
| 资源依附   | 行动者因关键资源渠道集中、不对称权力关系、替代不足和退出成本较高而形成的持续性资源依赖 |
| 替代能力   | 原有资源渠道失效或条件恶化时，通过其他渠道持续获得具有基本替代功能资源的能力      |
| 替代渠道   | 可用于替换原有资源来源、功能、制度渠道或关系渠道的现实资源路径             |
| 资源自主性  | 不依赖单一控制渠道而持续获取、配置和恢复关键资源的能力                 |
| 退出成本   | 终止、改变或转换既有资源关系时承担的经济、资格、关系、家庭、时间和恢复代价       |
| 资源阶梯   | 资源与资格沿行政和组织层级逐级配置的纵向结构                      |
| 资源控制者  | 能够影响资源准入、持续供给、使用权限和中断条件的主体                  |
| 预防性不进入 | 主体因预期风险和潜在资源损失，事先放弃进入某种职业、组织、经营或生活路径的适应行为   |
| 依附强化   | 原有资源关系的约束强度、覆盖范围或持续性增加                      |
| 依附转移   | 主体离开原有渠道后，转而依赖其他具有集中性或不对称控制关系的渠道            |
| 依附松动   | 替代渠道、资源自主性或退出能力增加，使原有资源关系的约束减弱              |
| 依附破裂   | 原有资源关系无法继续维持，但不必然意味着主体获得自主性                 |

**M2结构约束：**

- M2只有M2-a、M2-b、M2-c三个子模块。
- 替代能力、资源自主性和退出成本是贯穿三个子模块的共同分析维度。
- 预防性不进入是三类依附共有的事前适应形式，不是第四个子模块。
- 一般依赖、结构性依赖、制度性依附和政治性依附是识别层级，不是四个子模块。

## **2.3 M3：组织控制与行动约束机制（管）**

**正式定义**

M3是全控治理体系将权力转化为持续组织关系、制度边界与行为约束的机制。

其核心功能是**组织原子化**：国家通过组织嵌入、社会单位化、组织边界管理与信息上收，提高对社会的组织化控制能力，同时限制独立横向组织持续积累资源、规则、成员保护与集体代表能力。

其强化子模块是**选择性强制**，即通过针对性调查、处置与示范性威慑，提高独立组织行动的预期成本，使组织原子化在持续的社会压力下得以维持。

### **2.3.1 M3的两条控制轴线**

| 控制轴线 | 作用对象               | 主要内容                              |
| ---- | ------------------ | --------------------------------- |
| 对外控制 | 社会成员、家庭、企业、行业及社会组织 | 管理组织关系、活动边界与自主行动条件                |
| 对内控制 | 干部、官僚机构、地方政府及强制部门  | 通过任免、考核、监督、纪律、调查、处分和指挥链管理约束组织内部权力 |

两条轴线作用于不同对象，共同服务于组织权力的集中、传递与维持。

### **2.3.2 组织原子化**

组织原子化是M3的核心功能，指国家通过组织嵌入、社会单位化、组织边界管理、信息管理及选择性强制等安排，限制社会成员之间的横向联系发展为具有持续成员关系、共同规则、独立资源、成员保护、集体代表和跨组织协调能力的自主组织。

组织原子化不意味着：

- 社会成员之间不存在私人关系；
- 所有社会组织都被取消；
- 所有横向信息交流都被切断；
- 社会中不存在临时聚集、局部互助或熟人网络。

其核心是横向联系难以持续转化为自主组织能力。

### **2.3.3 M3的十项基本内容**

以下十项是主模型M3章节的基本内容。它们并非同一概念层级，暂按原有名称登记，不擅自合并为新的子模块。

| 序号 | 标准名称             | 概念说明                                       |
| -- | ---------------- | ------------------------------------------ |
| 1  | 组织嵌入             | 国家组织体系进入社会生活，建立持续纵向联系和组织节点                 |
| 2  | 社会单位化            | 将个人、家庭和社会主体划分为相对明确、可识别和可管理的组织单元            |
| 3  | 组织原子化            | 限制横向联系发展为具有持续自主能力的组织，是M3核心功能               |
| 4  | 组织边界管理           | 通过制度、程序和执行确定社会组织成立、发展、活动和对外联系的范围           |
| 5  | 对内纪律与权力约束        | 通过任免、考核、监督、调查、处分和指挥链管理约束统治组织内部成员与机构        |
| 6  | 选择性强制            | 通过针对性调查、处置和示范性威慑提高独立组织行动的预期成本，是组织原子化的强化子模块 |
| 7  | 基层执行与委托—代理扭曲     | 研究上级目标在地方和基层执行过程中产生的偏差及其组织条件               |
| 8  | 控制成本外部化          | 研究控制成本如何转移至社会主体、基层组织和其他承担者                 |
| 9  | 共谋均衡             | 研究组织成员、执行主体及相关参与者如何形成维持特定运行方式的相互适应关系       |
| 10 | 信息上收、组织过滤与行政信息管理 | 研究信息如何进入组织层级、被筛选和处理，以及组织信息渠道如何影响上报内容       |

### **2.3.4 M3的关键边界概念**

| 概念       | 定义                                           |
| -------- | -------------------------------------------- |
| 组织控制能力   | 国家能够调动的组织覆盖、人员任免、资源管理、审批许可、信息收集、调查处分和指挥链控制能力 |
| 组织自主能力   | 社会组织或体制内组织在议题、资源、负责人、规则、成员保护和跨组织合作方面独立决定的程度  |
| 组织控制效果   | 控制手段实际改变组织行为及自主能力的程度                         |
| 横向确认     | 个体发现他人具有相似经验或判断，并修正对社会认知分布的认识                |
| 横向连接     | 个体之间形成持续的信息交换、互助和协作联系                        |
| 横向组织     | 持续合作形成稳定成员、共同规则、独立资源和持续行动能力                  |
| 横向组织能力   | 持续成员关系、共同规则、独立资源、成员保护、集体代表和跨组织协调等能力的综合       |
| 横向组织功能封顶 | 允许组织存在并承担一定功能，同时限制其持续积累独立资源、规则、成员保护和集体代表能力   |
| 组织吸纳     | 将既有社会组织的部分功能纳入正式治理体系                         |
| 行政指导     | 主管机构依据职责对组织活动提供规范、协调或监督                      |
| 组织渗透     | 外部权力进入组织内部，实际影响负责人、议题、资源、成员关系或重要决策           |
| 委托—代理扭曲  | 上下级之间因信息不对称、激励差异、监督局限和执行条件差异产生的实际执行偏差        |
| 选择性强制    | 针对特定对象实施差异化调查、处置和惩罚，以改变更广泛群体的行为预期            |
| 控制成本外部化  | 控制体系将部分控制运行成本转移给社会主体或其他组织承担                  |
| 共谋均衡     | 相关组织参与者通过相互适应和利益安排维持特定组织运行状态                 |

### **2.3.5 M3的理论边界**

M3不能与一般行政管理、公共服务、常规监管和正常组织管理等同。

登记备案、行政审批、基层治理、行业监管、纪律检查和执法活动本身均不足以证明组织控制机制存在。

只有当具体制度安排和执行过程实际限制组织自主决策、成员保护、资源积累、横向联系或持续行动能力，并有相应过程与结果证据时，才构成M3的分析对象。

# **第三部分　状态变量**

## **3.1 Q：国家可支配财力与治理资源空间**

**正式定义**

Q指国家在特定时期能够实际调动、自主支配，并用于维持国家机器运转、兑现治理承诺与实施政策控制的财政资源空间。

其核心是扣除刚性偿债、基础民生、社会保险及其他已经锁定的必要支出后，国家能够用于维持既有治理体系、调整资源配置和承担新增治理任务的有效财力。

### **3.1.1 Q的三个层面**

| 层面        | 定义                        | 核心观察对象               |
| --------- | ------------------------- | -------------------- |
| 资源汲取能力    | 国家从企业、居民、土地和国有经济部门取得资源的能力 | 税收、国有资产收益、土地收入、非税收入等 |
| 资源集中与分配能力 | 将分散资源集中到财政体系并在不同层级之间调度的能力 | 财政集中、央地关系、转移支付、预算安排  |
| 资源兑现能力    | 将取得和安排的资源转化为实际治理能力的能力     | 人员供养、公共服务、行政运行、政策执行  |

### **3.1.2 Q的测量边界**

Q不是：

- GDP；
- 社会财富总量；
- 名义财政收入；
- 单纯的财政预算规模；
- 国有金融体系的全部信贷规模；
- 政府能够宣布的政策支出总额。

Q需要综合考察收入来源、债务负担、支出刚性、政府间资源分配和实际兑现能力。

### **3.1.3 Q与三机制**

| 机制 | Q的作用接口         |
| -- | -------------- |
| M1 | 财政资源与绩效叙事的物质基础 |
| M2 | 财力、资源配置与依附关系兑现 |
| M3 | 组织供养、基层运转与控制资源 |

## **3.2 K：社会认知、现实评价与私人知识积累**

**正式定义**

K是社会认知、现实评价与私人知识积累的状态变量，描述社会成员在日常生活、信息接触和社会交往中，围绕国家权力、政治制度、公共政策、政府行为及治理结果形成的知识、事实判断、因果解释、价值评价与情绪反应，以及这些认知在社会关系中的隐藏、表达、传播、相互确认和分化过程。

### **3.2.1 K的六个观察维度**

| 维度        | 主要内容                |
| --------- | ------------------- |
| 经验与知识获取   | 直接经历、信息接触、私人知识来源    |
| 认知加工与现实解释 | 事实判断、因果解释、信息加工      |
| 现实评价与政治态度 | 价值评价、政治态度、情绪反应      |
| 私人认知与公开表达 | 偏好伪装、知识隐藏、公开表态      |
| 认知传播与共同确认 | 信息传播、社会比较、横向确认、公共知识 |
| 认知与行为接口   | 适应、抵抗、退缩、退出、表达与行动   |

### **3.2.2 K的动态时间尺度**

| 时间尺度   | 主要变化                             |
| ------ | -------------------------------- |
| 即时状态   | 情绪反应、注意对象、信息接触和表达情境              |
| 中期变化   | 知识积累、事实判断、现实归因、参照群体和表达调整         |
| 长期结构变化 | 私人知识结构、稳定评价倾向、公共话语环境、认知议程和代际知识传递 |

### **3.2.3 K的关键概念**

| 概念           | 定义                                           |
| ------------ | -------------------------------------------- |
| 私人知识         | 个体依据直接经验、信息接触和社会交往形成的现实判断、事实认识与价值评价          |
| 隐性不满         | 私人知识中的一种负面评价或情绪内容，不等于私人知识本身                  |
| 偏好伪装         | 个体在社会压力和风险预期下，选择与私人偏好不同的公开表达                 |
| 私人判断与公开表达的差距 | 个体内部判断与其公开表达之间存在的差异                          |
| 横向确认         | 个体通过交流、观察和传播，发现他人具有相似经验或判断                   |
| 公共知识         | 个体不仅知道某项事实或判断，而且知道其他人也知道，并认识到这种共同知晓具有一定公共可见性 |
| 锚点事件         | 能够集中社会注意力、使分散经验和判断获得共同识别机会的事件                |
| 偏好级联         | 个体公开表达和行为变化相互影响，导致表达或行动在群体中扩散的过程             |
| 行动门槛         | 个体在特定风险、收益和信息条件下，愿意公开表达或参与行动所需要达到的主观条件       |

### **3.2.4 K的边界**

K不是：

- 单一的不满指数；
- 政治反对程度；
- 反抗意愿；
- 公开支持率；
- 公开沉默程度；
- 集体行动能力。

私人知识、隐性不满、偏好伪装、横向确认和公共知识之间存在联系，但不能相互替代。

### **3.2.5 K与三机制**

| 机制 | K的作用接口           |
| -- | ---------------- |
| M1 | 私人认知、现实评价与政治解释   |
| M2 | 资源处境认知、替代能力与退出判断 |
| M3 | 私人知识传播、横向确认与组织边界 |

## **3.3 F：制度现实识别与纠错能力**

**正式定义**

F是全控型治理系统的制度现实识别与纠错能力状态变量，描述治理体系在特定时期通过社会侧和组织内部的信息渠道，持续获取真实社会信息，检验信息可靠性，理解复杂社会现实，完成组织层级传递，识别问题的实际成因，并将判断转化为有效政策和组织调整的能力。

### **3.3.1 F的六个基本环节**

| 环节    | 定义                      |
| ----- | ----------------------- |
| 信息获取  | 制度能否接触真实社会信息            |
| 真实性检验 | 信息能否通过不同来源核验            |
| 行政可读性 | 复杂社会现实能否转化为制度能够理解和处理的信息 |
| 层级传递  | 基层经验能否完整到达决策层           |
| 问题解释  | 决策层能否识别问题的实际成因          |
| 政策纠错  | 能否将判断转化为有效政策和组织调整       |

### **3.3.2 F的关键概念**

| 概念     | 定义                                        |
| ------ | ----------------------------------------- |
| 社会反馈   | 社会成员、企业、组织和地方社会向制度提供的现实信息、经验和评价           |
| 国家内部反馈 | 行政层级、部门、基层机构及组织成员向决策体系传递的信息               |
| 行政简化   | 将复杂社会现实转化为统一分类、指标和行政可处理信息的过程              |
| 社会可读性  | 社会现象和现实经验能够被制度识别、描述、统计和处理的程度              |
| 地方实践知识 | 依赖具体环境、日常经验和实际操作形成的情境性知识                  |
| 指标化治理  | 通过指标、统计口径和量化标准组织行政管理和政策执行                 |
| 信息过滤   | 信息在收集、上报、传递和处理过程中受到选择、删减或重新组织             |
| 反馈失真   | 制度获得的信息与实际社会情况之间出现偏差                      |
| 双重冻结   | 社会侧真实反馈受阻与组织侧真实信息上报受阻同时存在的状态              |
| 反馈债务   | 制度未能及时识别和处理现实问题，由此形成的未纠正问题、信息失真和政策调整成本的累积 |

### **3.3.3 F的测量边界**

以下内容不能单独作为F的直接测量值：

- 投诉数量；
- 报告数量；
- 数据库规模；
- 监督频率；
- 政策调整次数；
- 行政检查数量。

F需要观察信息获取、真实性检验、信息传递、问题解释和实际纠错的完整过程。

### **3.3.4 F与三机制**

| 机制 | F的作用接口           |
| -- | ---------------- |
| M1 | 现实信息能否修正政治解释     |
| M2 | 资源需求识别、配置与兑现纠错   |
| M3 | 组织执行能力与现实识别能力的分离 |

## **3.4 Q、K、F的符号规范**

| 标准符号 | 标准名称             | 说明   |
| ---- | ---------------- | ---- |
| Q    | 国家可支配财力与治理资源空间   | 状态变量 |
| K    | 社会认知、现实评价与私人知识积累 | 状态变量 |
| F    | 制度现实识别与纠错能力      | 状态变量 |

符号规则：

1. Q、K、F为统一标准符号。
2. Q(t)、K(t)、F(t)表示相应状态变量在特定时间的状态。
3. Q与Q(t)、K与K(t)、F与F(t)不是不同变量。
4. K与k不作大小写区分，统一使用K。
5. 需要表达变化率时，不得将状态变量本身与变化率混为一谈；应另行明确表达。
6. 不得仅凭变量名称推断其数值、方向、权重或变化阈值。

# **第四部分　治理状态**

## **4.1 治理状态的基本定义**

治理状态是M1、M2、M3与Q、K、F在特定历史条件下形成的整体运行状态。

S1、S2和S3不是单纯的控制强度等级，而是治理体系主导逻辑、机制组合和协调能力的不同状态。

## **4.2 S1：常态治理**

S1是治理体系通过常态化制度安排维持政治秩序的状态。

主要特征：

- M1提供政治意义、合法性解释和现实评价框架；
- M2通过身份、生活供给和私人资本等资源关系维持制度依附与利益交换；
- M3通过组织嵌入、行政管理和行动约束维持日常秩序；
- 社会问题仍能通过既有制度渠道得到一定处理；
- 制度保留识别问题、传递负面信息和调整政策的能力。

S1不意味着不存在社会不满、政策失误或局部强制。

## **4.3 S2：强化治理**

S2是治理体系将强化控制作为处理压力或实现政治目标的优先方式，持续提高安全控制、组织约束、政治动员或风险管理强度的治理状态。

### **4.3.1 S2-D：防御型强化治理**

治理体系在感知到既有秩序受到压力时，以维护现存权力结构和降低不确定性为主要目标，持续提高安全控制、组织约束和风险管理强度。

主要触发条件：

- 社会抗议；
- 经济压力；
- 财政收缩；
- 公共危机；
- 外部冲击；
- 治理失败。

主导逻辑是防止现有秩序失稳。

### **4.3.2 S2-O：攻势型强化治理**

统治中心主动利用既有政治、财政和组织能力，重新配置权力关系、资源分配和政治忠诚的强化治理状态。

主要特征：

- 主动权力重组；
- 组织整肃；
- 权力隔离；
- 纪律审查；
- 选择性强制；
- 政治忠诚重建。

权力继承窗口是S2-O容易出现的重要情境。

### **4.3.3 S2-V：愿景驱动型强化治理**

治理体系以转型性总体愿景为中心，要求社会为尚未实现的未来目标承担现实成本，并通过政治动员、资源重组和组织控制推动社会按照既定方向发生整体变化的状态。

主要特征：

- 未来愿景承担现实解释功能；
- 资源配置服从总体目标；
- 组织动员范围扩大；
- 地方实践知识和负面反馈可能受到排斥；
- 现实绩效可能被未来承诺暂时替代。

## **4.4 S3：危机重构状态**

S3是原有M1、M2、M3组合无法继续以既定方式吸收压力，权力、资源和组织协调关系出现重新配置现实压力的状态。

S3不等同于政权崩溃，也不意味着所有治理机制同时失效。

其核心是原有治理组合无法恢复有效协调，制度进入不确定的重构过程。

### **4.4.1 S3-M：群众侧触发路径**

S3-M是群众侧触发路径，指社会成员分散的私人知识和现实评价，在特定条件下通过横向确认与公共知识形成，改变公开表达和集体行动门槛，并可能使社会侧压力超出既有治理组合的吸收能力。

### **4.4.2 S3-E：精英侧触发路径**

S3-E是精英侧触发路径，指统治精英内部的权力协调、共同承诺和联盟关系发生实质性破坏，原有权威结构无法通过内部谈判、资源重新分配或组织整肃恢复统一协调，由此使治理体系进入危机重构。

### **4.4.3 S3-M与S3-E的关系**

两条路径可以分别发生，也可能相互作用。

- S3-M强调社会侧私人知识、横向确认、公共知识与集体行动。
- S3-E强调统治精英内部的权力协调和联盟关系。
- 两条路径都需要结合M1、M2、M3以及Q、K、F进行判断。

# **第五部分　第二层：社会与人格结构性后果**

第二层研究第一层治理机制长期作用于社会之后，社会组织结构、社会心理、行为策略和人格倾向发生的变化，以及这些变化对治理体系产生的反向影响。

第二层不是新增治理机制，而是治理机制的长期社会后果及其反馈结构。

## **5.1 社会组织结构与横向关系**

| 概念       | 定义                                  |
| -------- | ----------------------------------- |
| 社会自主组织能力 | 社会主体独立建立组织、制定规则、积累资源、保护成员和代表共同利益的能力 |
| 横向信任     | 社会成员之间基于平等关系形成的信任，而非对上级或资源控制者的纵向依附  |
| 纵向依附     | 个体或组织依赖上级权力、组织身份或资源供给者形成的关系         |
| 强连带      | 具有较高互动频率、信任和相互支持的社会关系               |
| 弱连带      | 联系较弱但能够连接不同社会群体、传播信息和扩大关系范围的社会关系    |
| 网络桥接     | 不同社会关系网络之间形成信息和关系连接的过程              |
| 封闭网络     | 内部关系较密集，但与外部网络连接较少的关系结构             |
| 集体行动能力   | 社会成员将共同诉求转化为协调行动并维持行动的能力            |
| 组织代表     | 组织汇集成员利益、表达共同诉求并与外部主体交涉的能力          |
| 成员保护     | 组织为成员提供支持、保障和风险分担的能力                |

## **5.2 社会心理与行为适应**

| 概念        | 定义                                                                                  |
| --------- | ----------------------------------------------------------------------------------- |
| 社会问题私人化   | 原本具有公共或结构性性质的问题，被个体理解和处理为私人风险与个人责任                                                  |
| 风险规避      | 个体通过减少暴露、避免冲突和降低不确定性来控制潜在损失的行为方式                                                    |
| 防御性行为     | 个体为保护自身及家庭资源而形成的防御性行为策略                                                             |
| 沉默        | 个体选择不表达真实判断或不参与公开讨论的行为                                                              |
| 自我审查      | 个体在表达前主动评估风险并限制表达内容                                                                 |
| 低暴露策略     | 个体通过减少公开参与、降低可见性和避免敏感联系控制风险                                                         |
| 退缩化       | 个体减少公共参与、社会联系或组织活动的行为倾向                                                             |
| 关系化行为     | 在规则不确定或正式渠道不足时，依靠私人关系解决问题的行为方式                                                      |
| 工具化行为     | 将关系主要作为获取资源、机会和保护的工具                                                                |
| 控制化行为     | 个体通过控制自身或他人的行为降低不确定性和潜在风险                                                           |
| 策略性服从     | 个体基于利益、风险或资源约束而采取的外在服从，不必然意味着私人认同                                                   |
| 形式性合规     | 以满足外部检查、考核或程序要求为主，而未必完成实质任务                                                         |
| 避责        | 个体或组织通过请示、留痕、转移责任和限制自主决定降低个人责任风险                                                    |
| 隐蔽抵抗      | 个体在不公开对抗的情况下，通过规避、拖延、消极执行或其他方式降低对治理要求的配合程度                                          |
| 制度性社会心理异化 | 个体在长期处于高制度依附、低规则可预期性、横向信任受限和有限退出的社会环境中，为降低风险而形成关系化、工具化、防御化与控制化行为策略，并在持续社会化后逐渐形成稳定倾向 |

## **5.3 群体差异与社会分层**

主要观察维度：

- 身份资产与制度位置；
- 生命阶段与代际差异；
- 体制内外群体；
- 精英、中产与底层；
- 不同职业和行业；
- 资源依附结构；
- 退出能力；
- 家庭资源；
- 社会网络；
- 风险承担能力。

群体身份不能直接决定行为结果，必须结合资源结构、制度位置、家庭责任和替代能力分析。

## **5.4 家庭社会化与代际传递**

| 概念       | 定义                                       |
| -------- | ---------------------------------------- |
| 家庭风险教育   | 家庭成员通过经验和日常交流传递对制度、社会风险和行为边界的判断          |
| 代际行为策略传递 | 父母或上一代将风险规避、关系使用、沉默和服从等行为策略传递给下一代        |
| 制度社会化    | 个体通过家庭、学校、组织和社会环境学习制度规则、行为边界和社会期待        |
| 实践倾向     | 个体在重复实践中形成的相对稳定的行为判断和行动习惯                |
| 惯习滞后     | 原有环境中形成的行为倾向，在环境改变后仍然持续发挥作用              |
| 反向修正     | 下一代依据新的社会环境和个人经验，对上一代传递的行为策略进行接受、拒绝或重新组合 |

## **5.5 社会能力的衰减与再生成**

| 概念       | 定义                                    |
| -------- | ------------------------------------- |
| 社会自主能力   | 社会主体独立组织、协调、解决共同问题和维护自身利益的综合能力        |
| 自主组织能力   | 社会主体建立和维持自主组织的能力                      |
| 横向信任能力   | 社会成员建立超越私人熟人关系的横向信任的能力                |
| 公共知识形成能力 | 社会成员将分散私人知识转化为共同知晓的公共知识的能力            |
| 社会协作能力   | 社会成员在共同规则下持续合作和分担责任的能力                |
| 自我协调能力   | 社会主体不完全依赖外部命令，自主处理内部事务和协调共同问题的能力      |
| 组织能力衰减   | 自主组织的成员、规则、资源、代表和协调能力逐渐减弱             |
| 公共知识形成受阻 | 私人知识无法充分传播、相互确认和形成公共可见性的状态            |
| 社会能力再生成  | 社会主体在新的制度和社会条件下重新建立组织、信任、协作和公共知识能力的过程 |

# **第六部分　机制与状态变量的接口字典**

## **6.1 九个基本接口**

| 状态变量 | M1：意义建构        | M2：资源依附          | M3：组织控制          |
| ---- | -------------- | ---------------- | ---------------- |
| Q    | 财政资源与绩效叙事的物质基础 | 财力、资源配置与依附关系兑现   | 组织供养、基层运转与控制资源   |
| K    | 私人认知、现实评价与政治解释 | 资源处境认知、替代能力与退出判断 | 私人知识传播、横向确认与组织边界 |
| F    | 信息反馈、现实解释与叙事修正 | 资源需求识别、配置与兑现纠错   | 信息上收、组织过滤与执行纠偏   |

九个接口是治理机制与状态变量之间的关系，不是九个新机制。

## **6.2 K—M3—F接口**

| 对象        | 所属层级   | 研究内容                    |
| --------- | ------ | ----------------------- |
| 私人知识      | K      | 个体实际掌握的经验、事实判断与现实评价     |
| 隐性不满      | K      | 私人知识中的负面评价或情绪内容         |
| 偏好伪装      | K      | 私人偏好与公开表达之间的策略性分离       |
| 横向确认      | K      | 个体发现他人具有相似经验或判断         |
| 横向连接      | 社会关系过程 | 个体形成持续的信息交换、互助与协作联系     |
| 横向组织      | 社会组织结构 | 持续合作形成稳定成员、共同规则和独立资源    |
| 信息管理与组织过滤 | M3     | 组织结构和控制过程对信息表达、收集、传递的影响 |
| 制度信息      | F      | 进入制度系统并被获取、核验、解释的信息     |
| 信息反馈      | F      | 社会侧和组织内部向制度提供现实信息的过程    |
| 反馈失真      | F      | 制度获得的信息与实际社会情况之间出现偏差    |
| 政策纠错      | F      | 制度依据真实信息调整政策和组织安排       |

**接口边界：**

- K研究社会成员实际知道什么、如何理解和评价现实。
- M3研究组织结构与控制方式如何影响信息传播、表达和横向组织条件。
- F研究制度能否获得真实信息、识别问题并完成纠错。
- 私人知识不等于制度信息。
- 信息传播不等于公共知识。
- 横向确认不等于横向组织。
- 信息上报不等于真实反馈。
- 问题被发现不等于政策已经纠错。

# **第八部分　理论定义与使用规则**

## **8.1 概念层级规则**

1. 核心机制、状态变量、治理状态、内部概念和第二层后果必须分层登记。
2. 不得将某一现象同时作为机制、状态变量和结果重复计算。
3. 概念之间存在关联，不意味着它们属于同一层级。
4. 经验观察维度不自动成为独立理论概念。
5. 理论概念不自动需要独立符号。

## **8.2 变量使用规则**

1. Q、K、F是状态变量，M1、M2、M3是治理机制。
2. 不得将M1、M2、M3与Q、K、F混为一谈。
3. 不得仅凭符号推断变量数值、权重和变化阈值。
4. 不得将相关性直接写成因果关系。
5. 动态变化必须说明作用方向、时间顺序、作用条件和反馈过程。

## **8.3 机制边界规则**

- M1研究政治意义生产、合法性建构和现实解释。
- M2研究资源依附、替代能力和退出约束。
- M3研究组织控制、组织边界和行动约束。
- Q研究国家实际可支配财力和治理资源空间。
- K研究社会认知、现实评价和私人知识。
- F研究制度获取真实信息、识别现实和纠错的能力。

同一现实事件可以同时涉及多个机制，但必须分别说明每个机制的具体作用过程，不能仅凭事件名称或表面现象进行归类。

## **8.4 证据规则**

每个理论条目应区分：

- 正式理论定义；
- 由定义推导的机制解释；
- 案例经验支持；
- 尚待验证的假设；
- 历史遗留或非标准表达。

不得将案例中的分析性符号自动提升为正式理论变量。

不得将尚未经过经验检验的因果推论写成已经证实的规律。

本字典以2026-09-20主模型为核心定义依据。

后续修订应保留：

- 修改原因；
- 概念层级变化；
- 符号变化；
