## 0. 使用说明与版本纪律

本字典是全部理论材料的**本体锚点（ontological anchor）**，不是又一份正文。任何新材料在写入正文之前，先在这里完成"本体映射审查"——确认它归属哪个 Level、映射到 M1/M2/M3 中的哪一个、是否与既有条目冲突。

**文档优先级（v1.2 简化确立）**：

1. **2026-08-17-reload.md —— 唯一主要来源**。凡本文档明确表述之处即为 canon；与其他三份文档冲突处，一律以本文档为准。v1.1 曾设立的"新—新冲突逐案标记"特别处理规则，因其针对性问题（2026-08-16-read.md 与 2026-08-17-reload.md 何者更优先）已被本轮明确裁定取代，v1.2 起停用，不再需要。
2. **2026-08-16-read.md —— 参考来源**。与主源不冲突之处，作为补充内容纳入。
3. **reload.md —— 早期版本／形式化参考库**。其形式化内容（公式、显式变量）未被主源触及、亦无实质冲突之处，继续保留为当前最完整表述——"早期"只在发生冲突时让位，不等于整体作废。
4. **文章汇集.md —— 素材库**。提供部分子机制的精修阐释，不构成独立权威，可作为补充说明来源。

**冲突判定标准**：

- 主源**明确表述**某构念，其表述即为 canon，不论其他文档表述是否不同或更简略。
- 主源**未提及**某构念，而其他来源提供且不与主源已表述内容产生逻辑矛盾，则作为补充保留，标注来源——"未提及"不构成"冲突"，不触发让位。
- 主源与其他来源在**同一构念、同一分析层次**上给出彼此无法共存的不同具体内容（如不同的子类型划分方式），以主源为准，旧表述降级记入第 10 节，不再作为 canon。
- 主源与其他来源给出的内容**分属不同分析层次、可以共存**（例如"A(t) 一般架构"与"针对 κ(t) 的专项阻断工具"），则均予保留，分别注明适用范围，不强行择一——这不是"新旧各让一步"的折中，而是准确识别二者本来就不是同一个问题的答案。

## 2. Level 1：核心本体

Level 1 严格限定为四个不可化约的原初构念：**M1、M2、κ(t)、M3**。在其之上（生成性基础）与之间（合成函数）另有若干紧邻构念，单列为 2.5 节"核心系统函数"，不计入 Level 1 编号，但同等重要。

### 2.0 OER 服从交换关系（生成性基础，先于 M1/M2/M3）

- **定义**：国家与个体/组织围绕政治服从、制度参与与资源分配形成的非对称交换结构。个体让渡服从、参与、行为约束与认同，换取国家提供的秩序、安全、资源分配、社会身份与发展机会。
- **形式表达**：OER → {M1, M2, M3}（正当化 / 制度化 / 物质化三重展开，分别对应 M1/M2/M3）——2026-08-17-reload.md 1.1.2 明确将此表述为"三重相互支撑的制度维度"，与既有定义完全一致。
- **非对称性**：国家掌握交换规则制定权、资源配置权与强制执行权；个体只能在既定框架内做适应性选择。
- **内生悖论（双重冻结）**：体制越成功地将社会成员纳入服从交换网络，越可能压低社会真实反馈能力；社会侧表现为私人知识（κ(t)）隐蔽积累与冻结，国家侧表现为感知能力退化与反馈冻结——"社会越来越沉默，国家越来越相信沉默"。
- **来源**：2026-08-17-reload.md 1.1（主源，"双重冻结"表述即出自此处）；reload.md 1.1.5；2026-08-16-read.md 开篇

### 2.1 M1：合法性与叙事构建机制

- **定义**：政权持续再生成统治正当性、并为 M2/M3 提供意义支撑的机制集合；OER 的**正当化**维度。
- **总产出函数**：L(t) = α₁·L_perf(t) + α₂·L_hist(t) + α₃·L_sec(t) + α₄·L_inst(t)，权重 α₁~α₄ 为相空间状态依赖参数（见第 4 节）。此形式化公式为 reload.md/2026-08-16-read.md 给出，2026-08-17-reload.md 对四组件的实质内容（绩效/历史叙事/安全外部威胁叙事/规训内化与元认知框架）表述一致，仅未重复列出显式公式——不构成冲突，公式予以保留。
- **经验测量边界**：L(t) 对应受众**公开表达与合规行为**，不是私下真实认同。
- **双重效应**：短期——以低成本维持公开合规与心理顺从；长期——M1 棘轮效应（详见 3.1 节各组件），压制早期预警信号，侵蚀绩效纠错能力。

### 2.2 M2：控制与原子化机制

- **定义**：切断个体间横向社会联结、系统性阻断私人不满向可识别集体压力转化的机制集合；OER 的**制度化**维度。核心功能 A(t)（组织原子化）与强化子模块 D(t)（选择性强制）相互支撑、动态闭环。
- **综合效能函数**：Φ(t) = f(A(t), D(t))，联合效应高于线性加总。
- **双重效应**：短期——低成本维持高威慑—成本比 D(t)、压制横向协调；长期——D(t) 饱和效应、基层自利性扭曲、共谋均衡的时间不一致性共同侵蚀名义与实际控制力的一致性，极端情形下终结于治理网格的物理性断裂（见 3.2 节）。

### 2.3 M3：资源与激励分配机制

- **定义**：通过选择性物质激励与制度性捆绑，使个体退出体制的机会成本随时间非线性累积的机制集合；OER 的**物质化**维度。
- **总产出函数**：B(t) = f(E_capacity, H_supply, T_program)。三重区分（M3-a/b/c，见 3.3 节）是对 B(t) 构成性质的定性说明。
- **心理机制补充（2026-08-17-reload.md 1.4.1 主源新增内容）**：M3 绑定的微观有效性不仅取决于当期显性物质分配，更依赖个体对"未来机会"的心理预期——经济高速增长期，即便政治观念上缺乏认同，功利理性计算也会因可预期的职业发展与财富积累前景而抬高不合作的相对代价；这一预期一旦转向悲观（经济下行、增量枯竭），M3 对顺从的锁定效能随即被削弱。
- **双重效应**：短期——个体化激励结构分化协调主体、加固原子化；长期——M3-a 中间态积累、M3-b 稳定性承诺违约、M3-c 政治风险保护费的筛选效应，共同构成不断累积的隐性财政/信任负债。

### 2.4 κ(t)：私人知识积累速率

- **定义**：个体私人知识存量 K_private(t) 的微观净增速率：κ(t) = dK_private(t)/dt。是与 M1/M2/M3 相对的"对偶力量"。
- **四维分解**：κ(t) = a·κ_perception(t) + b·κ_attribution(t) + c·κ_comparison(t) + d·κ_normative(t)（详见 5.1 节）。**此形式化分解为 reload.md 独有**，2026-08-17-reload.md 仅在"私人不满"一章以定性方式讨论来源、归因位移、去魅与觉醒，未给出四维公式——不矛盾，保留形式化版本为 canon，同时以主源的定性论述充实各维度的实质内容（见 3.1/5.1 节）。
- **经验地位**：理论必要但经验不可直接观测，只能通过代理信号估计。行为数据（出国、资产转移）为其存在提供间接印证，但只能捕捉有能力退出的一小部分人，是旁证而非核心证据（2026-08-17-reload.md 明确强调此点）。
- **持存性假设**：倾向于持久存量而非自然衰减——日常一般性不满可通过表达/讨论逐渐消化，但本框架所刻画的私人知识，其消化渠道恰被 M2 系统性阻断，个体从未有机会说出、比对、获得确认，因而更可能长期留存而非自然淡去。

| 非正式吸纳 | 弹性协商、利益让步、将反抗精英收编入体制边缘，把社会不满转化为局部利益诉求并加以满足，剥离冲突政治色彩（含 reload.md 所举市长信箱、信访特批、定向协商等具体例证，作为本机制的补充细化） |
| 选择性执法 | 基层官僚"睁一只眼闭一只眼"的策略性放任，为社会保留隐蔽自生空间与交易通气孔，降低规则刚性伤害 |
| 策略性模糊 | 决策层在敏感领域故意维持政策文本与法律边界的模糊性，既保留上级随时收紧的自由裁量权，又为下级与民间留出因地制宜的缓冲地带 |

**功能定位**：与信访制度构成对照——信访是正式渠道、系统性失效；柔性响应是非正式、个案性，往往能给出真实可观测让步。效果是延后（而非消除）S1→S2 切换的触发时点。

### 4.4 S3 重构危机

| 子状态 | 触发条件（须同时满足） | 驱动核心 |
|---|---|---|
| S3-M 群众驱动型 | 来源于下层；规模超越 A(t) 当前效能水平的遏制能力；目标直接指向政权政治存续；体制从危机解决者转变为被挑战对象 | κ_sys(t) 在大众层面完成向公共知识 PublicKnowledge(t) 的级联转化 |
| S3-E 精英驱动型 | ≥2 具相当资源基础的行动者/派系；分裂性质超越常规政策分歧，进入对"谁有权代表体制正当性"的实质争夺；已从私人评估转化为精英群体广泛共享认知；强制/分配机制的指挥权或分配权威本身进入可观测争议状态 | ρ₄ 在精英联盟内部的跨行动者级联转化——尚未获得与 κ(t) 同等完整的形式化表达，为框架承认的理论缺口 |

**二者非互斥**：可共现且相互强化——主源 2.3.3 明确称之为"社会驱动与精英驱动的机制对称性与正反馈耦合"：社会爆破直接暴露体制脆弱性、击碎精英"统治幻觉"，加速官僚从"合规性怠政"向"避险式离心"跨越；精英内爆导致官僚消极怠工使控制网络出现大量漏洞，专政机器犹疑失灵释放"国家控制力已竭"信号，诱发更广泛的偏好伪装解体。

**三种解出方向**（对 S3-M/S3-E 同样适用）：回归 S1′／固化更深 S2／结构性重组。**人事更替与三种解出方向正交**。

**结构性重组的经验子类型**（以 2026-08-17-reload.md 4.4.3 为准）：

| 子类型 | 内容 | 与 Level 0.2 的兼容性说明 |
|---|---|---|
| 碎片化军阀割据与地方化秩序 | 地方官僚精英与残余强力部门结合，保留局部财政汲取与治安控制能力，防区演变为独立割据实体 | 仍属结构性重组内部子类型，不构成新状态 |
| 无政府状态下的无序动荡与社会解体 | 公共服务彻底中断、法律约束力归零，生存资源争夺演变为原生暴力冲突，局部区域沦为无政府黑洞 | 仍在 S3 内部描述"重组失败/未完成重组"状态，不构成新状态 |

### 4.5 S2 的分岔路径体系（主源两层递进细分，v1.2 系统化整理）

主源在两处分别给出了描述"高压治理逼近承载极限时可能走向"的分岔框架，二者不是相互竞争的表述，而是**粗粒度与细粒度的递进关系**：

**第一层（粗粒度，主源 2.4.1）——三种相变解出路径**：

| 路径 | 内容 | 对应 |
|---|---|---|
| 恢复性相变 | 决策层及时感知不可逆内耗，主动收缩控制、回归常态治理 | 大致对应 S3 三种解出方向中的"回归 S1′"，但发生在**未触发 S3 之前**——这是 S2 自身的降维回归，性质更接近于成功规避 S3 分岔 |
| 断裂性相变 | 社会驱动爆破与精英驱动内爆深度耦合，专政机器骤然失灵，极短时间内发生结构性断裂 | 对应 S3 的触发本身 |
| 滞留性相变 | 系统既丧失退回常态的政治信任与行政弹性，又凭借残存控制资源压制住社会爆破与精英内爆的彻底爆发，被硬性"冻结"为长期高消耗、高脆弱的"亚稳定停滞"均衡 | 对应 4.6 节"持续性均衡"，是同一现象的另一种命名 |

**第二层（细粒度，主源 4.1.2）——四种系统分岔路径**：此框架是对"断裂性相变"内部构造的展开，同时把"滞留性相变"保留为独立分支：

| 分支 | 内容 | 与第一层对应关系 |
|---|---|---|
| 持续性停滞分支 | 国家机械维持高压控制，社会萎缩、精英怠政，经济动能衰退但未爆发即时大规模抗争，长期陷入低水平系统性停滞 | 对应"滞留性相变" |
| 社会爆发分支 | 底层长期成本压迫下完成私人知识横向系联，焦点事件催生公共知识，搭便车算计失效，集体行动门槛级联坍塌 | 对应"断裂性相变"中以 S3-M 为主的具体实现 |
| 精英内爆分支 | 无限责任制彻底扭曲官僚激励结构，从基层到中高级干部普遍"策略性怠政"，统治集团内部信任崩塌、集体弃船 | 对应"断裂性相变"中以 S3-E 为主的具体实现 |
| 复合解体分支 | 社会显性抗争爆发、官僚体系内部瘫痪与财政体系全面枯竭在同一时间窗口重叠，形成深层复合对冲，是最剧烈且不可逆的演化形态 | 对应"断裂性相变"中 S3-M 与 S3-E 复合共振的情形，即第 6.4 节"复合临界状态" |

### 4.6 持续性均衡（Sustained Equilibrium，即"滞留性相变"/"持续性停滞分支"）

P_cascade(t) 是动力学概率函数而非确定性函数。系统维持在 S2（或 S1—S2 往复振荡）而不触发 S3-M 的充分条件，精确表述为 PublicKnowledge(t) < Θ_action^eff(t) 持续成立。**长期未触发 S3 不是理论解释力的失效，而是相空间在触发条件未达阈值时的内生合法解**。三项结构性代价：S2 领域经济摩擦、M3 领域流动性承压、S1 领域叙事结构替代。

## 6. 三条临界路径登记

主源为"临界路径"给出的编排是：精英内生分裂路径（→ S3-E）、信息穿透路径（→ S3-M）、外部约束路径三条并列表述；第四章另有一条高度具体化的财政—强制力复合崩解叙事链条，性质上是前两条路径复合触发的一种展开场景而非独立第四路径（理由见 6.6 节说明），故本字典维持"三条主路径 + 一条复合展开链条"的编排，不生造第四条平行路径（Level 0.8 已注明此编排选择不受路径数量锁定约束）。

### 6.1 EC-Path 精英内生分裂路径 → S3-E

三条内生化路径：①安全机构自主化扩张（Svolik 权力共享困境）；②M3 资源约束期零和竞争（Bueno de Mesquita 胜选联盟理论）+ 精英循环停滞（Pareto）；③M1 过度人格化侵蚀集体问责。继承问题为最高概率触发场景。

**主源第四章的具体机制展开（v1.2 新增，充实 EC_collapse 各阶段的行为内容）**：

- **隐性博弈期的微观基础**：庇护—依附网络与"伪共谋"结构（见 5.6 节）——体制内规则秩序被高度人身化的政治依附取代，公开拥护与实际消极执行并存。
- **公开信号期的触发**：顶层通过无限责任制与忠诚测试试图重建控制，反而引发政治安全感赤字的深度蔓延与忠诚从信念向"对冲博弈"的降级（见 5.6 节）。
- **临界博弈期的爆发链条**：强力部门软性抗命（避免成为未来历史替罪羊）→ 精英派系公开切分（不同派系为自保拒绝执行顶层指令，甚至向社会抛出顶层责任以换取政治赦免）→ 国家对强制力独占宣告坍塌。

### 6.2 IT-Path 信息穿透路径 → S3-M

κ(t) 连续累积 + T1（锚点事件）离散触发。关键变量：Δt_censor（审查下架延迟窗口）、N_crit（临界传播阈值）、δ_censor(t)（审查系统当期有效拦截率）。

T1 事件的核心性质：三重叙事吸收机制（个体化归责/外部威胁对冲/历史渐进主义对冲）对其同时失效——无法下移归责、无法外部归因、无法模糊处理。

**主源对私人知识微观系联的具体刻画（v1.2 补充 M(t) 的实质内容）**：符号化与隐喻表达（暗语系联，通过谐音梗/隐喻词汇/讽刺性梗/文化暗号/图像密码进行低风险隐秘试探）；边缘化与弱联系网络（寄生于日常兴趣/同乡熟人/职场交集构成的"去政治化弱联系网络"）；去中心化默契的微建构（对官方话语虚饰性的共同洞察）。

### 6.3 EC-Ext Path 外部约束复合路径

三条子路径：技术供应链约束（压低 M2 上限）／国际金融约束（压低 M3 财政容量）／境外信息穿透（压低 M1 叙事垄断）。内外交叉传导：外部地缘高压 → L_sec 应激升级 → M1 棘轮效应提前突破。φ(t)/δ(t) 显式公式未见于主源，来自 reload.md，不矛盾保留。

### 6.4 复合临界状态（Composite Criticality）

三路径激活概率峰值共享同一宏观时间窗口（经济增速换挡期）。判定条件：精英分裂追踪指标与大众级联追踪指标同时突破临界阈值。对应 4.5 节"复合解体分支"。

### 6.5 Scenario D（适应性让步）与可信度陷阱

**成功窗口四条件**：临界前时机／不可逆可信度构造／秩序底线的选择性维持／外部环境约束宽松度。**可信度陷阱**：C(t,H) 与 L_sec_share(t) 联合加速腐蚀让步可信度；三条时间套利偿还路径的时间轴重合，使 Scenario D 最需要实施的历史时期恰是财政、信息、叙事三方面条件最差的时期。

### 6.6 财政—强制力复合崩解链条（主源第四章独有，作为 EC-Path × IT-Path 的复合展开场景登记）

**定位说明**：此链条并非与 EC-Path/IT-Path/EC-Ext Path 并列的独立第四路径，而是主源第四章明确定位的"多维危机叠加"——社会横向动员（IT-Path 终端）、精英内生分裂（EC-Path 终端）与财政汲取枯竭三者复合触发的一种高度具体化的历史展开场景，故登记于此，不改变"三条主路径"的编排。

**链条**：统治成本膨胀与税基侵蚀的交叉剪刀差（支出端网格化维稳刚性负担持续上升，收入端市场主体因合规成本挤压萎缩）→ 治理网格物理性断裂（见 3.2 节）→ 地方财政割据与防区化自保（见 3.2 节）→ 债务违约与公共服务瘫痪的复合冲击（隐性政治债务集中兑现击穿体制信用幻觉；医保/养老金/市政基础设施因运维资金枯竭而频发瘫痪，生存危机直接取代对高压统治的恐惧）→ 强制力垄断解体与秩序真空（强力部门瘫痪后去中心化秩序真空出现，社会自发展开自救网络重组）。

此链条的分析价值在于：明确展示了 EC-Path 与 IT-Path 并非在复合临界状态下才发生互动的两条独立线——它们共享同一个上游财政诱因（M3 收缩），且各自的终端失效形态（强力部门抗命 / 治理网格物理断裂）本身就是彼此的加速器，这正是 4.4 节"复合解体分支"和 6.4 节"复合临界状态"在具体历史场景中的完整实现。
